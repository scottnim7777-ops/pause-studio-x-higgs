# 29차 시안 — 3차 히어로 개선 (2026-10-08)

사용자 요청: 3차(가로로 흐르는 작업물 벽 + 마우스에 따라 기울어짐)가 좋음. 대신
폰트 교체 · 로고 키우기(헤더 버튼 크기는 유지) · 양산형 버튼 탈피 · 누적 작업/평균 오픈 기간을 크게, 윗글과 정렬, 카운팅 · 오른쪽 아래 0원 다이얼 삭제 · 빨간 점 삭제 · 조각나서 나타나는 인트로 교체 · 새 문구.

## 새 문구 (사용자 확정)
- 한인 비즈니스를 위한 브랜딩 스튜디오
- 선택받는 브랜드는 / 보여지는 방식이 다릅니다.
- 웹사이트 제작부터 AI 영상 제작까지, / 브랜드가 고객에게 보여지는 모든 순간을 만듭니다.

## 시안 (`hero/hero.html?v=a|b|c`)
| | 제목 서체 | 버튼 | 숫자 |
|---|---|---|---|
| A 조용한 갤러리 | SD 그레타산스 Light(78px), "보여지는 방식"만 Regular | 크림 면 + 선 테두리 사각 버튼(같은 폭), 긴 화살표 | 그레타산스 Thin 80px, 세로 구분선, 버튼 줄과 같은 폭 684px |
| B 에디토리얼 | SD 격동고딕2 Regular(74px) | 번호가 붙은 목록형(01·02, 위아래 가는 선, 오른쪽 화살표) | 격동고딕2 Light 84px, 목록과 같은 폭 690px |
| C 세리프 럭셔리 | Grandiflora One(84px, OFL) | 크림 면 버튼 + 밑줄 링크 | Grandiflora One 84px |

공통: 로고 204px(기존 122px, 메뉴 높이 중심에 맞춤) · 메뉴 16px·문의 버튼 13/22px 유지 · 빨간 점 → 가는 선 · 다이얼 삭제 · 관리비 $0은 숫자 줄 세 번째 칸 + 주석(정책 §10 문구).

## 인트로 (`&intro=1|2`)
1. 초점: 어둠 속 멀리 흐릿한 벽이 다가오며 선명해짐 → 제목 줄 단위로 올라옴 → 숫자 카운트(0→42, 0→2–3, $ 숫자가 굴러 0에 멈춤)
2. 작업물 하나: 동대문 작업물이 화면 앞에 정면으로 떠 있다가 3D로 벽 속 제자리로 날아가 꽂힘, 주변 벽이 함께 나타남

## 렌더
`NODE_PATH=/opt/node22/lib/node_modules NODE_USE_ENV_PROXY=1 node tools/render_v29.cjs --v a [--t 8 | --fps 30 --dur 6.5] [--intro 1|2] --name still-a`
- 산돌 서체(그레타산스·격동고딕2)는 산돌구름 공식 테스터 페이지 안에서만 렌더(폰트 파일 추출·저장 없음). 테스터가 한 번에 100자까지만 서체를 만들어서 글자 묶음별 패스로 나눠 그린 뒤 합성: 벽 → 벽 속 캡션 → 그라데이션·로고 → 문구.
- 브라우저에서 hero.html을 직접 열면 산돌 서체 대신 시스템 서체로 보임(실제 사이트는 산돌구름 웹폰트 구독 필요 — 스탠다드 월 33,000원·2종).
