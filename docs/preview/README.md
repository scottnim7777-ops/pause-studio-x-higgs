# 사이트 미리보기

배포용 빌드(`npm run build`)를 브라우저로 연 화면입니다. 폰트는 사이트에 직접 넣은 무료 폰트(나눔스퀘어 네오 + Archivo)라 실제 사이트와 같습니다.

- 정지 화면이라 히어로 인트로·작업물 벽 흐름·영상은 움직이지 않습니다(영상은 첫 장면).
- 가격은 뉴질랜드 밖에서 접속했을 때의 화면(US$1,990)입니다. 뉴질랜드 IP로 접속하면 같은 숫자에 NZ$만 바뀝니다(NZ$1,990).
- 관리비 $0과 계산기는 움직임이 끝난 화면입니다.
- `pc-1440-first-screen.jpg`: PC 1440×900 첫 화면
- `pc-1440-full-1~5.jpg`: PC 1440 전체 페이지(위에서부터 5조각)
- `mobile-390-first-screen.jpg`, `mobile-390-full-1~3.jpg`: 모바일 390(2배 해상도) 첫 화면·전체
