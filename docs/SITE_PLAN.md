# PAUSE STUDIO 사이트 기획 v2 (2026-10-07)

기준: `docs/BUSINESS_POLICY_2026-10.md`(내용·가격) · 사용자 원칙 "아티스트가 만든 것처럼 고감도".
v1(“멈춤” 콘셉트, CSS 위주 연출)은 사용자 피드백으로 폐기:
> PAUSE 뜻을 살릴 필요 없음. Higgsfield 영상 능력 + Claude 코드 구현을 최대한 조합해 최첨단 기술력을 보여줄 것.
> CSS로 만든 허접한 영상 느낌 금지. 한국 디자인 기업이 쓰는 고감도 폰트. 효과·디자인·폰트·에셋·버튼·배치·무드·톤 모두.
> 남들이 스크롤에 영상을 묶는 것처럼(우리는 그 방식 자체는 필요 없음) 창의적으로.

## 1. 핵심 아이디어 — "AI가 찍고, 코드가 합성한다"

| 역할 | 담당 | 이유 |
|---|---|---|
| 촬영(공간·빛·카메라 무빙·재질) | **Higgsfield** (Seedance 2.0 1080p, Soul Cinema) | 실사 같은 영상미는 코드로 못 만든다 |
| 화면 속 내용(실제 고객 웹사이트·가격·글자) | **Claude 코드(WebGL)** | AI는 글자·화면을 왜곡한다. 실제 작업물은 AI로 만들면 안 된다(정책 §16) |
| 둘을 합치기 | **실시간 합성**: 영상의 화면 부분 모서리를 프레임마다 추적해 둔 데이터로, 브라우저에서 실제 웹사이트 영상을 원근에 맞춰 끼워 넣고, 화면 빛이 주변(바닥·벽)에 번지게 함 | 영상 속 화면이 진짜 고객 사이트라 정확하고, 마우스·스크롤에 반응한다 |

→ 이 조합이 "AI 티 없음"과 "최첨단"을 동시에 해결한다. 영상 한 편이 아니라, **촬영된 공간 안에 실제 작업물이 살아 있는 사이트**.

## 2. 무드 · 톤

- 키워드: 건축적, 시네마틱, 조용한 럭셔리. 갤러리·쇼룸·건축 사진.
- 재질: 노출 콘크리트, 트래버틴(석재), 헤어라인 알루미늄, 리넨. 사람은 등장하지 않음(설정샷 느낌 차단).
- 빛: 해 질 녘의 낮은 빛, 창으로 드는 사선 그림자, 화면이 유일한 광원인 어둠.
- 색: 본 화이트(#EDEAE4) · 웜 그래파이트(#1A1918) · 석재 베이지. 포인트 색 없음 — 색은 작업물이 낸다.
- 화질: 필름 룩 그레이딩(살짝 눌린 하이라이트, 따뜻한 그림자), 얕은 심도, 느린 카메라.
- 금지: 네온·보라 그라데이션, 유리 효과, 3D 기울인 카드, 이모지·아이콘 그리드, 카운트업 숫자, 별점 후기, 장식용 다이얼.

## 4. 히어로 — "작업물 전시관"

전체 화면 시네마틱 영상(Higgsfield) 4컷이 이어지는 약 20초 루프. 각 컷은 다른 건축 공간이고, 공간 속 화면/투사면에 **실제 고객 웹사이트가 실시간 합성**된다.

| 컷 | 공간(Higgsfield 촬영) | 화면에 합성되는 실제 작업물 | 카메라 |
|---|---|---|---|
| 1 | 어두운 콘크리트 홀, 벽 전체 크기의 대형 LED 월. 화면이 유일한 광원, 바닥에 반사 | K-VIBE(영상 사이트) | 느린 전진 돌리 |
| 2 | 트래버틴 쇼룸, 오후 사선 빛, 받침대 위 노트북 한 대 | DONGDAEMOON | 옆으로 흐르는 트래킹 |
| 3 | 갤러리 흰 벽에 프로젝터 투사, 먼지 입자가 빛줄기에 보임 | Blooming / 기타 작업 | 낮은 각도에서 상승 |
| 4 | 밤 비 오는 오클랜드 거리의 쇼윈도 너머 화면(유리 반사·빗방울) | CHILLENQ | 느린 줌인 |

- 컷 전환: 코드 효과가 아니라 **Higgsfield로 만든 실제 물질 영상**(먹물이 물에 퍼짐, 빛 번짐, 천이 스침)을 밝기 마스크로 써서 전환 → 손으로 만든 듯한 유기적 전환.
- 카피: 영상 위 왼쪽 아래 **브랜드는 더 돋보이게. / 매달 관리비는 없게.** — 그레타산스 Light. 오른쪽 아래 지금 컷의 작업물 캡션(업체명 · 업종), 컷과 동기화.
- 하단: 설명 한 문장 · "PAUSE Studio 기본 월 관리비 $0*" · 버튼(아래 7번) · 주석.
- 마우스: 영상이 커서 쪽으로 아주 살짝 시차 이동(카메라가 반응하는 느낌), 화면 속 사이트는 원근 유지.
- 모바일: 같은 공간을 **세로 9:16으로 따로 촬영**(잘라 쓰지 않음). 카피는 영상 아래.
- 성능: 첫 프레임 정지 이미지 즉시 표시 → 영상 로드. 저사양·절전 모드에서는 미리 합성해 둔 mp4로 대체.

## 5. 사이트 전체에서 Higgsfield × 코드가 만나는 곳

| 섹션 | 연출 |
|---|---|
| 작업(포트폴리오) | 목록에서 업체명에 올리면, 그 작업이 히어로와 같은 시네마틱 공간 속 화면에 합성되어 떠오름(WebGL 실시간). 클릭하면 공간으로 카메라가 들어가며 상세 화면 전환 |
| 서비스 3종 | 각 상품명(WEBSITE / ONLINE STORE / ENTERPRISE) 거대한 글자 **안에서** 그 상품을 상징하는 시네마틱 영상이 재생(글자 마스크). WEBSITE=빛이 건축 파사드를 훑음, ONLINE STORE=포장 상자가 닫히고 리본이 묶임, ENTERPRISE(AX)=정밀 기계 장치가 맞물려 돌아감 |
| 관리비 $0 | 영수증 프린터가 종이를 뽑아내는 매크로 촬영(Higgsfield). 종이 위 숫자는 코드가 추적 합성 → 1월 $0.00, 2월 $0.00 … 정확한 글자. 옆에 무료 범위/별도 비용 표(숨김 없음) + 다른 업체 월 관리비 입력 계산기 |
| 홍보영상(극장) | SOOM 이야기 영상(소리 있음, 찰칵 → 고화질). 화면에 보이면 무음 재생 + "소리 켜고 보기" |
| 섹션 전환 | 먹물·빛 번짐 물질 영상을 마스크로 써서 다음 섹션이 번져 나타남(스크롤 위치에 영상을 묶는 방식이 아니라, 전환 순간에 한 번 재생) |
| 문의 | 마지막 화면은 히어로의 LED 홀로 돌아와, 화면에 상담 폼이 합성되어 있음 |

## 6. 페이지 순서
1. 히어로(작업물 전시관) → 2. 선언(대표 직접 제작, 템플릿이 아닌 맞춤 디자인) → 3. 작업 → 4. 서비스·가격(WEBSITE $1,990 · ONLINE STORE $4,490부터 · ENTERPRISE 맞춤 견적, AX 먼저 · NZD/USD 안내) → 5. 관리비 $0 → 6. 홍보영상(극장) → 7. 과정(50% · 수정 2회 · 50% · 인계) → 8. 소유권·직접 관리 → 9. FAQ → 10. 문의.
문구는 `docs/CONTENT_POLICY_AUDIT.md` 기준. 미검증 숫자·가짜 후기·경쟁사 비교표 없음.

## 7. 버튼 · 세부
- 버튼: 얇은 1px 테두리의 긴 직사각형, 그레타산스 Regular. 올리면 안쪽이 작은 시네마틱 영상(그 버튼의 행선지와 관련된 장면)으로 차오름. 카카오톡 버튼도 같은 형식(노란 기본 버튼 쓰지 않음, 작은 마크만).
- 커서: 기본 커서 유지, 작업물 위에서만 "VIEW" 라벨이 따라옴.
- 스크롤: 부드러운 관성 스크롤, 글자는 줄 단위 마스크로 등장.

## 8. 제작 방식(기술)
1. Higgsfield로 공간 촬영: 화면 부분은 **단색 그린/마커가 있는 빈 화면**으로 촬영 → 추적이 쉬움.
2. Python(OpenCV)으로 프레임마다 화면 네 모서리 추적 → JSON.
3. 브라우저(WebGL): 배경 영상 + 실제 웹사이트 영상 텍스처를 모서리 데이터로 원근 변형, 화면 빛 번짐·반사·필름 그레인을 셰이더로.
4. 그린 부분 가장자리 처리(키잉), 색 맞춤(화면 텍스처에 공간의 색온도 적용).

## 9. 진행 순서와 비용
1. **1컷 기술 시연**: 컷 1(LED 홀) 하나를 실제로 촬영·추적·실시간 합성해 브라우저에서 보여줌 — Seedance 1080p 5초 ≈ $3.4, 재촬영 포함 ≈ $10.
2. **서체 시편**: 그레타산스 등 후보로 실제 히어로 문구 조판(무료).
3. 승인 후 컷 2~4 + 모바일 세로 컷 + 전환 물질 영상 + 서비스·관리비 영상: 대략 $60~100(재촬영 포함 추정). 현재 크레딧 부족 → 충전 필요.
4. 전체 페이지 디자인 → "제작해" → 제작.
