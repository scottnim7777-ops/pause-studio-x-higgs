# PAUSE STUDIO 히어로 영상 — 최종 설계서 (2026-10-06)

## 0. 이 영상을 만드는 이유
- **보는 사람:** pause8studio.com에 처음 들어온 뉴질랜드 한인 대표님.
  - 지금 사이트가 후지거나, 관리비가 아깝거나, 홍보가 안 되는 사람이다.
- **3초 안에 생겨야 할 감정:** "이거 내 얘기네" → "이 회사 고급이다".
- **끝까지 보면 생겨야 할 결론:** "사진만 있으면 영상도 사이트도 만들어 주고, 관리비도 안 받네. 상담 신청해 보자."
- **전할 메시지 (우선순위 순)**
  1. 사진 몇 장으로 고급 AI 홍보영상과 웹사이트를 만든다.
  2. 제작비는 한 번, 유지보수·관리비는 $0이다.
  3. 실제 한인 업체 작업이 많다.
- **영상의 역할:** 히어로 배경이다. 글자(제목·관리비 0원·상담 버튼)는 HTML로 고정하고, 영상은 그 말이 사실임을 보여주는 증거다. 영상 자체가 글로 설명하지 않는다.

## 1. 절대 원칙 — AI 티를 없애는 방법
1. **사람 컷과 화면 컷을 분리한다.**
   - 사람에게 화면을 들려 카메라 쪽으로 향하게 하는 구도는 금지한다.
   - 화면은 두 가지 방법으로만 보여준다.
     - 화면 녹화를 화면 가득 넣는다.
     - 위에서 내려다본 책상 위 휴대폰처럼 화면이 원래 카메라 쪽을 향하는 자연스러운 상황을 쓴다.
2. **실제 고객 파트에는 AI 사람을 쓰지 않는다.**
   - 실제 사이트와 실제 영상만 쓴다.
   - 한인 사회가 좁아서 가짜 사장님은 신뢰를 무너뜨린다.
   - AI 사람은 가상 브랜드 SOOM 이야기에만 쓴다.
3. **AI 영상으로 만드는 것은 물리 현상과 카메라 움직임뿐이다.**
   - 허용: 물결, 액체, 빛, 그림자, 천천히 미는 카메라.
   - 금지: 손으로 하는 복잡한 동작(타자, 케이크 짜기)과 얼굴 연기.
4. **화면 속 글자와 UI는 절대 생성하지 않는다.**
   - 전부 실제 HTML을 녹화해 원근에 맞춰 합성한다.
   - 반사, 시야각에 따른 색 변화, 화면 밝기를 주변 빛에 맞춘다.
5. **실제 촬영의 불완전함을 넣는다.**
   - 비대칭 구도, 앞에 걸리는 물건, 핸드헬드 미세 흔들림을 쓴다.
   - 초점은 늦게 따라오게 한다.
   - 24fps, 셔터 180°의 움직임 흐림을 쓴다.
6. **색은 하나로 맞춘다.**
   - 한 영상에 색 보정 기준(LUT)을 하나만 쓴다.
   - 주황·청록 대비, 모든 컷이 따뜻하게 빛나는 느낌, 피부를 매끈하게 처리하는 것은 금지한다.
7. **컷 길이를 짧게 한다.** 사람 컷은 2초 이하로 해서 오래 보면 드러나는 AI 흔적을 피한다.

## 3. 화면 설계 (히어로 배경용)
- **글자 영역:** 왼쪽 40%는 HTML 제목과 버튼 자리다.
  - 영상의 주요 피사체는 화면 중앙에서 오른쪽에 배치한다.
  - 왼쪽은 어둡거나 단순하게 둔다. 사이트에서 은은한 그라데이션 마스크를 덧씌운다.
- **모바일:** 9:16 세로 편집본을 따로 만든다.
  - 2·7번(위에서 본 휴대폰)과 화면 녹화는 세로에 원래 잘 맞는다.
  - 사람 컷은 세로로 다시 프레이밍한다.
- **글자 가독성:** 영상 속 글자(알림)는 휴대폰 화면 너비 390px에서도 읽혀야 한다. 2·7번은 휴대폰이 화면 높이의 80% 이상을 차지한다.

## 4. 색·화질·움직임 규격
- **색:** 뉴트럴 필름 톤으로 한다. 검정은 살짝 띄우고, 하이라이트는 부드럽게 넘어가게 한다.
  - 밤: 차가운 중성색 (청록 금지)
  - 아침: 따뜻한 중성색
  - 광고 필름(5번): 파스텔
  - 화면 녹화: LUT를 약하게만 적용해 선명함을 유지한다.
- **질감:** 고운 필름 그레인을 전체에 동일하게 넣는다. 주변부 어두움은 약하게 한다. 렌즈 색수차는 미세하게 넣는다.
- **움직임:** 24fps로 한다. 카메라 이동은 시작과 끝이 부드러운 감속 곡선이다. 핸드헬드 흔들림은 같은 강도의 노이즈를 모든 사람 컷에 적용한다.
- **납품:**
  - 1920×1080 H.264 (약 6–8MB)
  - WebM VP9
  - 1080×1920 모바일판
  - 무음
  - 포스터 이미지 = 로고 프레임
  - 이음매 검증: 첫·끝 프레임 차이가 평균 0.01 이하

## 5. 제작 순서와 비용
1. 콘티 스틸을 이 설계대로 다시 만든다. 1·2·7번 장면은 새 구도로 생성하고, 나머지는 기존 자산을 쓴다. (몇 센트)
2. 사용자가 승인한다.
3. Seedance image-to-video를 돌린다.
   - 대상: 1번 + 5번 3컷 = 4클립 × 5초.
   - 1080p 약 $13.6 (충전 필요). 720p 약 $6.
   - 광고 필름(5번)은 1080p를 권장한다.
4. 실제 사이트 녹화(Playwright 60fps), UI 애니메이션, 합성, 색 보정, 편집을 코드로 해서 재현할 수 있게 한다.
5. AI 티 검수 체크리스트를 통과하지 못한 클립은 버린다.
   - 손, 얼굴, 물체 위 글자, 물리 법칙, 깜빡임, 프레임 간 일관성, 화면 가장자리

## 6. 버린 것과 이유
- 사람이 화면을 카메라 쪽으로 드는 구도: 설정샷 느낌이 난다.
- 실제 고객 대표님을 AI로 연기: 아는 사람이 보면 신뢰가 깨진다.
- 금빛 물보라·노을 해변: 과하고 촌스럽다.
- 화면 속 설명 문구(채팅 등): 허접하고 이해가 어렵다.
- 다이얼·시계: 사용자가 거절했다.
