# eyecannndy 프레임 시트 메모 (s00–s07)
- Aerial: 흑백 보트 항적(위에서), 경기장 위 FPV, 구체 건물 + 노란 큰 타이틀(The Gentlemen 오프닝), 지붕 위 1인칭, 사막 위 작은 사람(Dune). → 실제 드론 필요, 정지 사진으로는 'Tilt shift'식 정적 항공샷만.
- Altered state: 어안 클로즈업, 조명 줄무늬, 터널 효과. 광고 톤과 거리 멂.
- Animation / Anthropo: 셀 애니·페나키스토스코프 원판(새들이 도는 원판!), 사물에 얼굴. 원판 = 원형 반복 → 로고(두 원)와 운율 맞출 수 있음(참고만).
- Arc: 인물 둘레를 원호로 도는 카메라(밤바다, 경찰). 실제 카메라 이동 → AI 영상 위험.
- Architexture: 건물 면이 애니메이션 텍스처로 움직임, 스테인드글라스 원형 창이 돎.
- Bolt Cam: 초고속 로봇 팔 카메라(Ray-Ban Meta, Severance). 흰 무대에서 휙 다가옴.
- Boomerang: 앞뒤로 되감기는 짧은 고리(무용수). → 편집 가능. 무용·패션에 어울림.
- BTS: 그린스크린·VFX 과정 노출(자동차 리프트 → 그린 스튜디오), 'DIRECTED BY' 타이틀, 빨간 원 무대 위 의자. ★ '우리가 실제로 만들었다' 증명에 정확히 맞는 기법: 완성 장면 → 뒤로 빠지며 촬영장(조명·슬레이트·모니터 속 PAUSE 로고)이 드러남.
- Bullet Time: 멈춘 시간 속 회전(흑백 군무, 칼이 떠 있는 방). AI 영상 필요.
- Camera Roll: 화면 전체가 180° 회전(노란 복도, 열쇠구멍 → 빨간 복도, 원형 스포트라이트 속 사람이 회전하며 떨어짐). 원형 스포트 + 회전 = 로고 원과 맞음.
- Central Framing: 정중앙 대칭(Espresso 2인, 숲 속 횃불, 웨스 앤더슨식 해변·도자기 물레 흑백).
- Choreo: 군무, 흰 커튼 앞 무용, 문틈 빛 속 실루엣 춤(흰 틈 + 그림자 — 강함).
- Cinemagraph: 사진 속 일부만 움직임(꽃 속 여인 정지, 빛 들어오는 방에서 붉은 천만 펄럭, 꿀 병 위 김). ★ 정지 사진이 대부분이고 작은 부분만 움직이므로 AI 영상의 물리 오류가 생길 자리가 없음. 김·물결·빛·천 정도만 움직이기.
- Close-Up: 노란 휴대폰 카메라 렌즈 속 데이지(Apple Hello Yellow), 타르트 위 크림, 얼굴 클로즈업(Severance).
- Collage: 카세트테이프 배경 속 인물, 잡지 오린 조각.
- Color Shift: 같은 장면이 컬러 → 흑백 → 다른 색으로(Espresso 군중, 흑백 사진 같은 군중), 얼굴 위 빨강 → 파랑 조명 전환(윌리 웡카), 파란 눈 → 맨눈. → 편집에서 색 바꿈 한 번으로 '시간·감정 전환'.
- Conveyor: 무대 세트를 옆으로 밀듯 장면이 이어짐(웨스 앤더슨 기차 칸, 흑백 패션 군상이 옆으로 흐름, 머그샷 벽 → 트로피 소녀). → 가로로 긴 한 장의 사진 위를 옆으로 이동(트럭)하면 정지 사진만으로 가능.
- Crash cut: 시장 → 갑자기 열기구 하늘(크래시 줌 + 컷), 빨래줄 하늘 → 흰 새.
- Cut-ins: 같은 장면에서 더 가까운 부분으로 툭 잘라 들어감(인물 전신 → 가슴, 라이터 불꽃, 슬라이드 뷰어 속 사진(★ 손에 든 작은 슬라이드 뷰어 안에 장면이 보임)). → 한 장의 고해상도 사진 안에서 잘라 들어가기 = 정지 사진만으로 가능.
- Datamosh: 픽셀이 녹아 흐름. 광고 톤과 맞지 않음.
- Diorama: 미니어처 세트(장난감 차·병정), 얕은 심도. Fantastic Mr. Fox.
- Distortions: 유리·물결 굴절, 흑백 표현주의 계단.
- Dolly: 천천히 다가감(인물·담배 불붙이기 Malena), 빨간 배경 + 세로 대문자 타이틀 'REMA'(★ 타이포 배치 참고), 수족관 원형 창.
- Dolly Zoom: 배경이 늘어나고 인물은 그대로(Severance 흰 복도, 사막 위 콘크리트 덩어리). 깊이 지도가 있으면 정지 사진으로 흉내 가능(배경층만 확대·축소).
- Double Dolly: 인물과 카메라가 함께 미끄러지듯(스파이크 리) — 실제 이동 필요.
- Double Exposure: 두 장면이 겹침(무대 위 가수 + 얼굴, CD 빛, 구름 속 얼굴, Dior 흑백 인물들 사이로 비치는 숲). → 편집으로 가능, 과하면 촌스러움. 흑백 + 한 겹만.
- Dreamcore: 텅 빈 교외·몽환 색. 맞지 않음.
- Duplication: 같은 인물이 여럿(테니스장, 식당, 문 두 개에서 같은 사람). 
- Dutch Angle: 기울인 구도(Mission Impossible, A Serious Man).
- Dystopian: 맞지 않음.
- Echo print: 잔상이 남았다 따라붙음(군중, 걷는 남자들, 형광 실루엣 잔상). → 저프레임 + 프레임 합성으로 가능. 패션·무용.
- Epiphany: 깨닫는 순간의 표정(줌인·조명 변화). 
- Falling: 위에서 본 침대 위 여자가 떨어지는 듯(★ 침대 시트 = 하늘, 스톱모션), 보트, 하늘로 낙하.
- Fast Motion: 타임랩스·빨리감기(체스, 회전목마 장노출, 숲속 인물). → 사진 연속 촬영(타임랩스) 느낌 = 정지 사진 여러 장으로 가능.
- Feedback: VHS·CRT 잡음, 주사선. 
- First-Person / Fisheye: 1인칭 달리기, 어안 렌즈 스케이트. 
- Fixed Cam: 물체에 카메라를 붙임(차 옆, 오토바이 핸들, 자전거) — 배경만 흐름. 
- Flash Cut: 같은 구도의 사진 여러 장을 아주 빠르게(자전거 실루엣 → 은색 자전거 → 고전 자전거: ★ '같은 모양의 다른 물건'을 0.1초씩 이어 붙임, 같은 포스터가 여러 벽에 붙은 모습, 영화 크레딧 카드 속 사진이 바뀜). → 정지 사진만으로 리듬감 있는 광고. 원(두 고리) 모양 물건을 연달아 = 로고와 운율.
- Floating UI: 인물 옆에 문자 말풍선·카드가 떠 있음(House of Cards). 웹 에이전시 광고로는 너무 흔함.
- Focal shift: 초점이 앞 → 뒤로 옮겨 감(Fantastic Mr. Fox, 부엌의 두 사람). → 깊이 지도로 정지 사진에서도 가능. ★ 고급 광고의 기본 문법.
- Fourth Wall: 카메라를 보고 말 걸기.
- Freeze Frame: 움직이다 멈추고 이름 자막(타란티노·가이 리치), 사진 스튜디오에서 카메라를 든 남자, 파파라치 플래시. ★ 'PAUSE'라는 이름과 직결: 움직임이 '멈추는' 순간 = 정지 사진이 그대로 작품이 됨.
- Generative: 노골적 AI 이미지 — 피해야 할 예.
- Gesture: 손으로 화면 넘기듯 현실을 넘김(인스타그램).
- Ground Level: 바닥 높이 카메라(부츠, 자동차 아래).
