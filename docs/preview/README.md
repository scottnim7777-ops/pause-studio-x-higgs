# 사이트 미리보기 (실제 산돌 서체)

`site/tests/preview.cjs`로 만든 이미지입니다. 운영 사이트에는 산돌구름 웹폰트를 연결해야 이 모습이 됩니다(연결 전에는 시스템 고딕).

- 만든 방법: 산돌 공식 테스터 페이지 안에서만 그림(서체 파일을 내려받거나 저장하지 않음). 테스터는 한 번에 100자까지만 서체를 만들기 때문에, 글자마다 실제 서체의 폭을 재서 칸을 고정하고 100자 묶음마다 찍은 뒤 합쳤습니다.
- 정지 화면이라 히어로 인트로·작업물 벽 흐름·영상은 움직이지 않습니다(영상은 첫 장면).
- `pc-1440-first-screen.jpg`: PC 1440×900 첫 화면
- `pc-1440-full-1~5.jpg`: PC 1440 전체 페이지(위에서부터 5조각)
- `mobile-390-*.jpg`: 모바일 390(2배 해상도) 전체 페이지
