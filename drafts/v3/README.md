# 3차 시안 — 움직이는 히어로 (2026-10-06)

전략: `docs/HERO_VIDEO_STRATEGY.md` · 사용자 요청: 직접 만든 영상으로 보일 것 · 무한 반복 자연스럽게 · 관리비 무료 강조 · 비싸 보이고 첫 3초 후킹 · AI 티 없이 · 홍보영상 제작도 함.

- `hero.html` — 브라우저에서 바로 재생(마우스에 따라 벽이 기울어짐). `?loop=1`이면 인트로 건너뜀. 직접 열면 시스템 한글 서체로 대체 표시.
- `PAUSE_hero_v3_intro+loop.mp4` — 인트로 3.2초 + 반복 24초(ABC Favorit Hangul로 렌더링)
- `PAUSE_hero_v3_loop24s.mp4` — 반복 구간만 정확히 한 주기(무한 반복 재생해도 이음매 없음)
- 생성: `python3 tools/build_v3.py` → `node tools/record_v3.cjs` (디나모 공식 페이지 안에서 렌더링, 시간을 프레임마다 지정해 캡처)

## 구성
1. 인트로(첫 진입 1회, 3.2초): 격자 → 제목이 한글 자판 입력처럼 자모부터 조립 → 실제 작업물(Ref.03 동대문)이 조각으로 조립 → 뒤로 빠지며 작업물 벽 등장
2. 반복(24초 주기): 실제 작업물 15개가 원근 벽 3줄로 흐름(줄마다 한 주기에 정확히 한 세트 이동). 영상 작업물 4개(Ref.01 K-VIBE·02 Blooming·07 Global Blessings·04 오클랜드 여행사)는 실제 영상이 재생 — 8초씩 잘라 주기와 맞춤. 오른쪽 아래 12개월 다이얼이 한 바퀴(1달=2초) 돌아도 "0원 · 월·연 관리비 (무료)".
3. 고정 문구: 원문 헤드라인·설명·CTA 2개·누적 작업·평균 오픈 기간·안내 문구.
