# eyecannndy 프레임 시트 메모 (s24–s67, 기법당 클립 8개 × 처음·중간·끝 프레임)

## 광고에 바로 쓸 만한 것 (AI 티를 숨기거나 오히려 '손으로 만든' 느낌을 주는 기법)
- Halation: 밝은 부분 둘레에 붉은 번짐(필름 유제 반사). Uncut Gems·The Gentlemen. → 후반에서 하이라이트만 뽑아 흐리게·붉게·스크린 합성. AI 특유의 깨끗한 디지털 느낌을 지움.
- Haze: 뿌연 확산광(프로미스트 필터), 흑백 연무. → 하이라이트 블룸 + 대비 낮춤.
- Hard Light: 한 방향 강한 빛, 진한 그림자, 색 젤(빨강·청록). 얼굴 반만 빛.
- Light Flash: 어둠 속 스트로브 한 번에 장면이 드러남(회의실 플래시), 위에서 터진 플래시로 군중. → 정지 사진 몇 장 + 플래시 프레임으로 '셔터 순간' 연출, 움직임 없이도 박자감.
- Locked-On: 물체(턴테이블 레코드·휠·농구공)를 화면 가운데 고정, 세상이 그 둘레로 돎(Beats by Dre). → 후반 안정화/회전으로 가능.
- Magnification: 돋보기·루페가 종이 위를 지나며 글씨·지문을 크게 보여 줌(Zodiac, Grand Budapest). → ★ 명함·인쇄 교정지 위 루페로 PAUSE 로고를 보여 주기.
- Match Cut: 모양이 같은 두 장면을 잇기(눈 → 성냥 머리, 빨래줄 → 새). 원형 ↔ 원형.
- Match Split: 화면을 둘로 나눴는데 하나의 그림이 됨(얼굴 반쪽씩, 두 개의 바퀴).
- Overhead: 정수리 위에서 내려다본 평면 구도(턴테이블과 손, 침대들, 해변 위 원). 정물 연출에 강함.
- Parallax: 사진을 겹으로 나눠 앞뒤가 따로 움직이는 2.5D(시내트라 다큐). → 정지 사진을 영상처럼. 과하면 가짜 티, 아주 작게.
- Photography: 사진 자체를 장면으로(인화지·밀착 인화·신문). 플래시 사진 연속.
- Probe: 렌즈가 문구멍·열쇠구멍·카드 바로 앞까지 들어감(Deliveroo 'The Arrival' 햄버거, KitKat). 제품 매크로.
- Product: 회색 무대 위 향수 뚜껑 매크로(극도로 절제), 흰 원형 스튜디오의 자동차, 과일 더미 속 위스키 병, 밧줄 무늬 위 코냑 병(위에서). → 빈 공간 + 한 가지 빛 + 질감.
- Projections: 어두운 방, 실루엣 뒤로 풍경이 투사됨. 얼굴에 프로젝션 매핑. 사람 위에 빛 무늬. → ★ 벽에 떨어진 햇빛/고보 조명이 PAUSE 로고 모양(빛으로 로고를 '그려 넣음').
- Ratio Switch: 레터박스가 열리며 화면비가 바뀜, 세로 → 가로 분할. → 편집으로 바로 가능. '공개' 순간에 쓰기 좋음.
- Reflections: 선글라스·사이드미러·안경에 비친 장면. → 렌즈·유리에 비친 로고.
- Scale Shift: 거대한 가방을 든 작은 사람, 거대한 노트 위를 걷는 사람(원근 착시).
- Screen in Screen: 화면 속 화면(오래된 TV, 휴대폰 상단, 게임 태블릿).
- Shadow Box: 검은 바탕에 작은 사진 칸이 떠 있음(아기 사진 격자, 회전하는 다이빙 사진). → 편집만으로 고급 잡지 느낌.
- Silhouette: 역광 실루엣, 머리카락 윤곽만 빛남(플래시 역광).
- Slow Motion: 하늘에서 떨어지는 비닐봉지와 과일, 가스불 매크로, 눈을 천천히 감는 얼굴.
- Speed Ramp: 느렸다가 확 빨라짐(자동차 드리프트, 요트).
- Split Screen: 두 얼굴 나란히, 흰 띠 사이 인물.
- Step-print: 왕가위식 프레임 번짐(중경삼림 '600' 간판, 네온 속 사람). → 저프레임 + 잔상 합성. 흐림이 디테일을 숨겨 AI 티가 줄어듦.
- Stop Motion: 실패가 하얀 종이 위에 선을 그림, 블록이 줄지어 움직임, 위에서 본 침대 위 사람. → 같은 구도 사진 여러 장. 손맛.
- Tableau / Pedestal: 웨스 앤더슨식 대칭 정면 구도, 파스텔, 수직 이동(밀크셰이크 간판).
- Tilt Shift: 도시·항구가 장난감처럼(위 아래 흐림).
- Typography: 초록 바탕 세리프 제목('Dropping Seeds'), 밴 위에 큰 영문 로고(THE NORTH FACE/GUCCI), 고전 영화 타이틀. → 편집에서 직접.
- Video Portraits: 인물이 카메라를 가만히 봄, 아주 작은 움직임(블레이저 화보).
- Vignette / Voyeur: 망원경·쌍안경·문구멍 원형 시야.
- Vintage: 16mm 빛샘, 필름 번(타 들어감), 흔들리는 게이트.
- Void: 검은 무(無) 속 왕관·인물, 위에서 한 줄기 빛. → 제품 히어로 컷.
- Wigglegram: 3~4대 카메라로 찍은 사진을 번갈아 보여 주는 입체 흔들림(Kirby Gladstein, 켄드릭 'Humble'). → ★ 정지 사진 한 장 + 깊이 지도로 3~4개 시점을 만들어 '덜컥덜컥' 보여 주면, 매끈한 AI 움직임이 아니라 아날로그 사진 기법으로 보임.
- Zoetrope: 원형 무대 위 인물 실루엣이 회전하며 걸음(VW 'The Wheel').
- Zoom: 크래시 줌, 인물로 천천히 줌인.
