# PAUSE STUDIO 디자인 규칙 (2026-10, 32차 히어로 승인안 기준)

실제 값은 `site/src/styles/main.css` 맨 위 `:root` 토큰이 기준이다. 이 문서는 왜 그렇게 정했는지와 지켜야 할 규칙을 적는다.

## 1. 원칙
- **고감도**: 아티스트가 만든 것처럼. 폰트·배치·여백·움직임이 모두 의도가 보여야 한다. AI 양산형 웹사이트의 버릇(둥근 알약 버튼, 보라 그라데이션, 반짝이는 KPI 숫자, 과한 유리 효과, 아이콘 나열)을 쓰지 않는다.
- **실제만 보여 준다**: 포트폴리오·히어로 벽은 실제 고객 사이트 화면만. 예시(가상 브랜드 SOOM, 템플릿 예시 화면)는 반드시 예시라고 표시한다.
- **읽히는 크기**: 강조할 곳은 크게, 나머지 글씨도 작게 줄이지 않는다(본문 최소 16.5px, 보조 글 최소 14.5px, 주석만 12.5~13.5px).
- **사진은 승인된 것만**: 28차(시네마틱 공간) 자산과 영수증 프린터 합성 사진은 사용자 반대로 쓰지 않는다. 대신 글자 디자인(예: 1년치 $0 내역)으로 보여 준다.

## 2. 색
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` | #0C0C0B | 기본 배경(어두운 섹션) |
| `--ink-raise` | #151513 | 어두운 배경 위 상자(계산기) |
| `--black` | #060606 | 영상 섹션 |
| `--cream` | #FCEED8 | 어두운 배경의 글자·로고·주 버튼 (로고 색과 동일) |
| `--cream-2 / -3` | 82% / 58% | 보조 글·주석 |
| `--paper` | #EFE8DC | 밝은 섹션(대표 서신, 과정, FAQ 등) |
| `--on-paper` | #141311 | 밝은 섹션의 글자 |

어두운 섹션과 종이색 섹션을 번갈아 써서 긴 페이지에 호흡을 준다. 강조색(빨강·파랑 등)은 쓰지 않는다 — 강조는 크기·굵기·밑줄로.

## 3. 서체 (무료 · 직접 호스팅 — 2026-10-08 사용자: 산돌 유료 웹폰트 대신 가장 비슷한 무드의 무료 폰트)
| 역할 | 서체 | CSS |
|---|---|---|
| 제목·가격·큰 숫자 | **PS Display** = 나눔스퀘어 네오 Bold(한글) + Archivo 폭 70·굵기 500(영문·숫자) | `--f-display` |
| 본문 | **PS Text** = 나눔스퀘어 네오 Regular | `--f-text` |
| 버튼·강조 본문 | PS Text Bold(700) | `--f-text-md` |

- 고른 이유: 실제 산돌 렌더와 같은 문장·크기로 무료 후보 10종을 나란히 비교. 나눔스퀘어 네오(디자인 산돌)는 네모틀을 채운 한글이 격동고딕2와 가장 가깝고, Regular는 그레타산스와 본문 밀도·줄바꿈이 거의 같음. 격동고딕2의 좁은 영문·숫자는 Archivo 좁은 폭으로 맞춤.
- 프리텐다드·SUIT·IBM Plex Sans KR은 1차 시안에서 "허접하고 AI 티가 난다"는 의견으로 제외.
- 파일: `site/public/fonts/*.woff2`(사이트 글자 묶음 + 나머지 한글 2,350자 묶음, unicode-range), `scripts/fonts.py`로 생성. 라이선스 SIL OFL 1.1.
- 한글 줄바꿈: `word-break: keep-all`(낱말 중간에서 끊지 않음).
- 글자 간격: 큰 제목 -0.035em, 중간 제목 -0.02em, 본문 기본, 영문 머리말(eyebrow) +0.16em 대문자.

## 5. 버튼 (32차 A안)
- **주 버튼**: 크림색 네모 블록 + 긴 화살표(30px). 마우스를 올리면 왼쪽에서 밝은 크림색이 차오르고 화살표가 6px 나아간다.
- **보조 버튼**: 얇은 선(크림 40%) 네모 + 카카오톡 말풍선 + 긴 화살표. 마우스를 올리면 크림색이 차오르며 글자가 검게.
- **글자 링크**: 밑줄(8px 띄움) + 짧은 화살표.
- 둥근 알약 모양·그림자·그라데이션 버튼은 쓰지 않는다. 높이 76(PC)/56(모바일).

## 6. 배치
- 최대 폭 1720px, 좌우 여백 `--gutter`(20~100px), 섹션 위아래 `--sec-pad`(96~176px).
- 섹션 머리: 영문 머리말(짧은 선 + 대문자) → 큰 제목(줄마다 아래에서 올라옴) → 소개 글.
- 포트폴리오: 모든 작업물을 같은 크기·같은 비율(16:10) 칸으로 — PC 4열 × 4줄, 태블릿·모바일 2열(사용자 요청: 크기 통일).
- 상품 비교: 위 상품이 아래 상품에 '더하는 것'을 맨 위에 + 표시로 크게, 아래 상품에서 그대로 이어지는 것은 맨 아래에 작은 글씨 한 줄로(요금 카드·서비스 상세 모두).
- 서비스: 왼쪽에 이름·가격(따라 내려오는 고정 머리), 오른쪽에 설명·기능 목록.
- 선: 1px, 크림 20% 또는 잉크 16%. 상자 대신 선으로 나눈다.

## 7. 움직임
- 히어로 인트로(3.4초): 어둠 속 흐릿한 작업물 벽이 다가오며 선명해짐 + 제목을 한글 자판으로 치듯 자모부터 조립(ㅅ→서→선) + 깜빡이는 커서 → 설명·버튼·서비스가 차례로.
- 작업물 벽: 세 줄이 서로 반대 방향으로 24초에 한 바퀴, 마우스에 따라 살짝 기울어짐, 화면에 보이는 카드의 영상만 재생(PC).
- 등장: 화면에 들어오면 26px 아래에서 1초 동안 올라옴. 제목은 줄마다 가려진 곳에서 올라옴.
- 가속 곡선: `--ease cubic-bezier(.2,.7,.1,1)`(빠르게 시작해 부드럽게 멈춤).
- **멈출 수 있어야 한다**: 5초 넘게 움직이는 것(작업물 벽·자동 재생 영상)에는 멈춤 버튼. '움직임 멈추기'는 사이트 전체에 적용되고 기억된다. 운영체제의 '동작 줄이기'를 켜면 인트로·자동 재생 없이 바로 최종 화면.
- 깜빡이는 표시(상담 가능 점)는 2번(5초 안)만.

## 8. 이미지·영상
- 포트폴리오: 실제 고객 사이트 화면(WebP + JPEG, 880/1920px), 영상은 H.264 MP4(소리 없음).
- AI 영상광고 예시: 가상 브랜드 SOOM — '예시 · 실제 고객 작업물 아님' 표시 필수.
- 템플릿 비교의 왼쪽(흔한 템플릿)은 HTML로 그린 예시 화면이며 특정 업체 사이트가 아님을 표시.

## 9. 접근성
- 키보드: 모든 버튼·링크 초점 표시(2px 선), '본문으로 건너뛰기', 창(상담·크게 보기)은 Esc로 닫고 원래 버튼으로 초점 복귀.
- 화면 읽기: 타이핑 제목은 전체 문장을 따로 읽어 줌, 오류 문구는 입력 칸과 연결, 진행 단계 표시.
- 대비: 크림(#FCEED8) 글자 / 잉크(#0C0C0B) 배경 대비 약 16:1.
- JS가 꺼져도 모든 내용이 보임(본문은 빌드 때 HTML로 만듦).
