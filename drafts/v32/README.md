# 32차 시안 — 히어로 (2026-10-08)

31차 검토: 인트로 1(초점)이 인트로 3보다 나음 → 인트로 1 확정, 인트로 3 삭제.
추가 요청: 3차 시안에서 만든 **제목 타이핑 효과** 적용.

- 제목을 한글 자판으로 치듯 자모부터 조립(ㅅ → 서 → 선, ㅌ → 태 → 택 …), 타이핑하는 동안 커서가 따라가고 끝나면 몇 번 깜빡이다 사라짐(0.5~2.05초 타이핑, 2.9초에 커서 사라짐).
- 벽은 인트로 1 그대로: 어둠 속 멀리서 흐릿하게 → 다가오며 선명해짐(0.1~2.5초).
- 제목 타이핑이 끝난 뒤 설명 → 버튼 → 서비스(위 선이 그려지고 두 칸이 차례로) → 주석 순서로 등장.
- 화면 구성·글씨 크기·카피는 31차와 같음(`drafts/v31/out/pc.png`, `mobile.png`).
- 렌더: `node tools/render_v29.cjs --dir drafts/v32/hero --out drafts/v32/out --v b --fps 30 --dur 7 --name intro-pc` (모바일 `--mobile --ch 1120 --z 2`)
  - 타이핑 중간 글자(자모·받침 전 글자)는 제목의 `data-x`로 서체 묶음에 포함.
