# 히어로 영상 전략 — "퍼온 영상이 아니라 우리가 직접 만든 것"으로 보이게 (2026-10-06)

사용자 피드백(2차 시안): 다 별로. 로고를 메인으로 쓸 필요 없음. **고객이 이 영상을 이 회사가 직접 만들었다는 걸 알 수 있어야 함.**

## 왜 2차가 '퍼온 영상'처럼 보이나
도시 야경·도자기·한지 같은 장면은 아무 회사나 살 수 있는 스톡 영상과 구별되지 않는다. 장면이 예뻐도 "이 회사만 가진 것"이 하나도 없다.

## 원칙: 스톡에는 절대 없는 것만 화면에 넣는다
1. **우리 실제 작업물** — 우리가 만든 고객 사이트 화면(Ref.01~15)이 영상의 주인공. 다른 회사 영상에는 있을 수 없다.
2. **만드는 과정** — 빈 화면 → 격자 → 한글 제목이 조판되고 → 사진이 들어가고 → 완성된 실제 사이트. "웹사이트를 만드는 곳"이 첫 화면에서 읽힌다.
3. **한글이 움직인다** — 자모가 모여 "한인 대표님들을 위한"이 조립되는 식. 해외 스톡 영상에는 나올 수 없는 장면.
4. **방문자에게 반응한다** — 마우스·스크롤에 따라 움직이는 화면은 녹화 영상이 아니라 그 자리에서 그려진다는 증거.
5. **하나의 서명** — 전환마다 같은 동작(예: 로고의 두 원이 열고 닫는 화면 전환), 같은 색·속도. 로고는 크게 쓰지 않고 이 움직임으로만 드러낸다.

## 만드는 방법
- **주 영상은 코드로**(HTML·Canvas·GSAP): 글자·화면·전환을 브라우저에서 직접 그림 → 선명하고 가볍고 반응형, 영상 파일 불필요. 같은 장면을 녹화해 SNS·소개용 MP4도 만든다.
- **실제 작업물 화면은 직접 녹화**: 고객 사이트를 실제로 스크롤하는 화면 녹화(Playwright), 기존 영상 작업물(Ref.01·02·07)은 원본 그대로.
- **Higgsfield(Seedance)는 보조로만**: 실제 작업물이 띄워진 노트북·휴대폰이 놓인 실제 공간(예: 그 업종의 매장 카운터) 같은 짧은 컷. 화면 속 내용은 생성하지 않고 실제 녹화를 합성해 고정(카메라 고정). 남은 예산 약 7.53 USD → 1080p 8초 1컷 또는 720p 약 20초.
- 장면마다 작은 캡션: "Ref.03 한식당 · 실제 제작 사이트"처럼 실제 분류명을 붙임.

## 방향 3가지
- **A. 라이브 제작 시연** — 히어로 자체가 사이트를 만드는 과정. 빈 화면 → 격자 → 한글 제목 조립 → 실제 작업물 3개가 차례로 완성 → PAUSE 첫 화면으로 정착(10~12초 루프). 코드 100%.
- **B. 실제 작업물 쇼릴** — 우리 고객 사이트들이 실제 기기 화면에서 스크롤되는 장면을 빠르게 이어 붙인 릴, 업종 캡션 포함. 일부 컷만 Seedance로 공간감.
- **C. A + B 혼합(추천)** — 첫 3초는 A(한글 조립·격자), 이어서 B(실제 작업물 릴), 마우스로 다음 작업물로 넘어감.
