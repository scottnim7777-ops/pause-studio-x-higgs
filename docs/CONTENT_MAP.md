- 원문: `content/site-content.ko.json`(기존 사이트 한국어 원문, 보존용 — 수정하지 않음)
- 새 문구: `site/src/content/ko.ts` (모든 화면 문구가 이 파일 한 곳에 있음)
- 바꾼 기준: `docs/BUSINESS_POLICY_2026-10.md`(사업 정책) · `docs/CONTENT_POLICY_AUDIT.md`(원문 대조표) · 사용자 확정 사항(STATE.md)
- **플랜(상품명·가격·기능)은 사용자 견적서 `docs/QUOTATION_2026-10-07.md`가 기준**(2026-10-08 사용자: "기존에 만든 견적서 안의 플랜 내용으로 교체") — 정책 문서의 WEBSITE·ONLINE STORE·식당 예시는 쓰지 않음
- 표시: **그대로** = 원문 유지 · **수정** = 정책·사실에 맞게 고침 · **새로** = 원문에 없던 내용 · **뺌** = 쓰지 않음

## 순서(새 사이트)
머리줄 → 히어로 → 포트폴리오 → 대표 서신(WHY PAUSE?) → 추천 대상 → 서비스(4종 + 기본 포함) → AI 영상광고 → 디자인 차이(Ordinary vs. Artisanal) → 기본 월 관리비 $0(무료·별도 비용, 계산기) → 제작 과정 → 요금 → 자주 묻는 질문 → 문의 → 푸터 · 상담 신청 창

기존 순서(히어로 → 서신 → 추천 → 포함 사항 → 과정 → 비교 → 포트폴리오 → 요금 → FAQ → 문의)에서 **포트폴리오를 히어로 바로 다음으로** 올렸다. 히어로의 작업물 벽을 본 사람이 곧바로 실제 작업을 크게 볼 수 있게 하기 위함.

## 사용자 확인이 필요한 것(임의로 만들지 않음)
- AI 영상광고 가격·범위(현재 "상담 후 견적").
- 누적 작업 수(확인 전 표시하지 않음). 제작 기간은 견적서의 "보통 2~6주"만 씀.
- Ref.16~39 소유 여부, 언어 선택 메뉴용 번역문.
- 미국 등 해외 사업장의 청구 통화(정책 §9는 'USD 같은 숫자', 견적서는 NZD만) — 현재 "상담 후 견적서에 안내".
