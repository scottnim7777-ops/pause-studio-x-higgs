## 0. v27이 실패한 이유 (솔직한 진단)

| 문제 | 원인 |
|---|---|
| 양산형 느낌 | 왼쪽 큰 헤드라인 + 버튼 2개 + 아래 3칸 장점 + 오른쪽에 비스듬히 기운 3D 카드 벽. 이건 SaaS 템플릿·AI 생성 랜딩의 기본 틀이다. 어두운 배경 + 필름 그레인 + 빛 스윕도 "프리미엄처럼 보이게 하는" 흔한 장치다. |
| 폰트가 촌스러움 | SD 정체는 신문·책 본문의 전통 비례를 가진 서체라, 98px로 키우면 '옛날 신문 제목'처럼 보인다. 그 전의 Pretendard·SUIT 등은 본문용 고딕이라 크게 써도 개성이 없다(양산형). 즉 "디스플레이용으로 설계된, 현대적 비례의 한글"이 필요한데 그 기준 없이 골랐다. |
| 세로 벽이 가로보다 못함 | 세로로 흐르면 웹사이트 화면(가로로 긴 화면)이 잘게 잘려 작업물이 안 보인다. 가로로 흐를 때는 작업물이 '전시'처럼 보였다. |

**교훈:** 장치(효과)를 더하는 게 아니라 하나의 콘셉트에서 출발해 덜어내야 한다.

## 1. 콘셉트 — "멈추게 하는 웹사이트"

- PAUSE = 멈춤. 사람들은 하루 종일 화면을 넘긴다. 좋은 브랜드 웹사이트는 그 손가락을 **멈추게** 한다. → 이것이 "브랜드는 더 돋보이게"의 시각적 증명.
- 사이트 전체를 **갤러리(전시)**처럼 만든다. 작업물이 주인공이고, 글자는 전시 캡션처럼 정확하고 절제된다.
- 시그니처 동작은 딱 하나: **흐르다가 멈춘다.** (히어로의 작업물 흐름, 홍보영상의 '찰칵', 스크롤 전환 모두 같은 문법)
- 리듬: 밝은 갤러리(사이트 대부분) → 어두운 극장(홍보영상 섹션) → 다시 갤러리. 어두운 '프리미엄 다크' 템플릿 느낌을 피하고, 영상 섹션만 극장처럼 어둡게 해서 대비를 만든다.

### 하지 않을 것
비스듬한 3D 카드 벽 · 네온/그라데이션 글로우 · 유리 효과 · 숫자 카운트업 · 아이콘 3칸 그리드 · 별점/후기 캐러셀 · 이모지 · 화면 구석의 장식용 시계/다이얼 · 근거 없는 실적 숫자 · 효과를 여러 개 겹치기.

## 2. 아트 디렉션

- **색**: 종이 같은 오프화이트 바탕(갤러리 벽), 먹색 글자, 작업물은 원래 색 그대로. 포인트 색은 하나만(시편 단계에서 2안 비교). 영상 섹션만 거의 검정.
- **그리드**: 12단, 좌우 여백 넉넉히, 비대칭 배치. 글자 덩어리를 화면 가운데 몰지 않는다.
- **캡션 문법**: 작업물마다 전시 라벨처럼 `번호 — 업체명 · 업종 · 작업 범위`. 사실만 쓴다(정책 §16).
- **모션**: 느리고 정확하게. 감속 곡선 하나로 통일. `prefers-reduced-motion`이면 정지 화면.

## 3. 서체 전략

원칙
1. 한글 서체 1종(디스플레이) + 본문 1종 + 라틴 1종, 그 이상 섞지 않는다.
2. 후보는 반드시 **실제 헤드라인 문장으로 PC·모바일 크기에서 비교한 시편 한 장**으로 고른다. 이름만 보고 고르지 않는다.
3. 라이선스가 웹 사용 가능한지 확인한다(무료 OFL 또는 구매).

후보 방향(시편에 올릴 것)
| 방향 | 인상 | 후보 |
|---|---|---|
| A. 고대비 디스플레이 명조 | 패션 매거진·갤러리. 획의 굵기 차이가 커서 크게 쓸수록 아름다움 | Grandiflora One(OFL), 을유1945(OFL, 본문 겸용) |
| B. 붓맛이 남은 현대 바탕 | 손으로 쓴 결이 보여 '사람이 만든' 느낌 | Diphylleia(OFL), Song Myung(OFL) |
| C. 개성 있는 현대 고딕 | 단단하고 건축적. 본문용 고딕과 다른 비례 | 산돌 격동굴림(상용, 산돌 테스터로 시편) |
| D. 헤드라인 전용 레터링 | "브랜드는 더 돋보이게. 매달 관리비는 없게." 16자만 직접 디자인한 글자(SVG). 진짜 스튜디오가 하는 방식 | A~C 중 고른 서체를 뼈대로 다듬음 |

- 이미 거절된 서체는 후보에서 뺀다: Pretendard, SUIT, IBM Plex, 고운바탕, 함렛, SD 정체, SD 격동명조2, AG 최정호, ABC Favorit Hangul(v3).
- 라틴 라벨·숫자($1,990, $0)는 한글 서체가 정해진 뒤 그에 맞춰 고른다.

## 4. 히어로

**목표:** 3초 안에 "이 집 작업물 수준이 높다"와 "관리비가 없다"를 동시에 전달.

구성(PC 1440×900)
- 위: 얇은 머리줄 — 로고 / 작업 · 서비스 · 가격 · 과정 · 문의 / 상담 신청.
- 가운데 띠(화면 폭 전체, 높이 약 45%): 실제 작업물 15개가 **평평하게 한 줄로 가로로** 천천히 흐른다(v3의 가로 흐름 유지, 3D 기울기·다이얼 제거). 영상 작업물 4개(K-VIBE 등)는 카드 안에서 실제 영상 재생.
- **시그니처:** 약 7초마다 흐름이 부드럽게 감속해 작업물 하나가 정확히 멈춘다. 멈춘 작업물만 사진이 현상되듯 선명해지고, 아래에 전시 캡션(번호 — 업체명 · 업종)이 나타난다. 2초 뒤 다시 흐른다. 마우스를 올려도 멈춘다(말 그대로 PAUSE).
- 아래 왼쪽: 헤드라인 2줄 **브랜드는 더 돋보이게. / 매달 관리비는 없게.**
- 아래 오른쪽 좁은 단: 설명 한 문장(정책 문구) · "PAUSE Studio 기본 월 관리비 $0*" · 버튼 2개(무료 상담 신청 / 카카오톡 상담) · *주석 한 줄(기본 호스팅·기존 기능 기술 보수 포함, 도메인·외부 서비스 비용 별도).

모바일(390×844)
- 위: 작업물 한 줄(카드 크게, 한 번에 하나 반 보임), 같은 멈춤 동작.
- 아래: 헤드라인 → 설명 → 관리비 한 줄. 버튼 2개는 화면 하단 고정 바.

구현: 영상 파일이 아니라 코드(HTML/CSS/JS)로 실시간 재생 → 선명하고 가볍다. 시안 확인용 영상은 같은 코드에서 프레임 캡처.

## 6. 홍보영상 섹션 (소리 있음)

- 흐름(확정안 유지): 밤의 청구서 알림 → 일시정지 → 대표가 찍은 평범한 제품 사진(포장 있음) → **찰칵**(셔터음·플래시, 이 순간부터 고화질) → 광고 장면 → 새 쇼핑몰 → "PAUSE Studio 기본 월 관리비 $0" → 로고.
- 고객 실제 사이트·제품은 넣지 않는다(가상 브랜드 SOOM). 로고의 두 원은 한 번만, 찰칵 순간에만.
- 사운드: 앰비언트 → 정적(일시정지) → 셔터음 → 음악이 열림. 소리 없이 봐도 이해되게 화면 글자는 최소.
- 길이는 이야기에 맞게(억지로 늘리거나 줄이지 않음). Seedance 1080p, 크레딧 충전 후 제작.
- 사이트에서: 화면에 보이면 무음 자동재생, "소리 켜고 보기" 누르면 처음부터 소리와 함께.

## 7. 진행 순서 (단계마다 승인받고 다음으로)

1. **이 기획 승인**
2. **서체 시편 한 장** — 3번의 후보들로 실제 헤드라인을 PC·모바일 크기에 조판, 색 2안 함께
3. **히어로 정지 시안** — PC·모바일 각 1장
4. **히어로 움직임 시안** — 실제 브라우저 코드 + 미리보기 영상
5. 나머지 섹션 디자인 → "제작해" → 전체 사이트 제작
6. 홍보영상은 서비스 확인·크레딧 충전 후 병행

## 8. 사용자 확인이 필요한 사실
- AI 홍보영상 제작을 사이트에서 서비스로 안내할지, 가격·범위(정책 문서 상품 목록에 없음)
- 누적 작업 수, 평균 제작 기간(확인 전에는 표시 안 함)
- 대표 사진·이름 공개 여부("대표 직접 제작" 섹션)
- 작업 목록에 올릴 업체 이름 표기 허락 여부, Ref.17~39가 실제 고객 작업인지
- GST 등록 여부
