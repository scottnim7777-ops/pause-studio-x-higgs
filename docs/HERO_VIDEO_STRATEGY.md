# 히어로 영상 전략 — "퍼온 영상이 아니라 우리가 직접 만든 것"으로 보이게 (2026-10-06)

사용자 피드백(2차 시안): 다 별로. 로고를 메인으로 쓸 필요 없음. **고객이 이 영상을 이 회사가 직접 만들었다는 걸 알 수 있어야 함.**

## 왜 2차가 '퍼온 영상'처럼 보이나
도시 야경·도자기·한지 같은 장면은 아무 회사나 살 수 있는 스톡 영상과 구별되지 않는다. 장면이 예뻐도 "이 회사만 가진 것"이 하나도 없다.

## 원칙: 스톡에는 절대 없는 것만 화면에 넣는다
1. **우리 실제 작업물** — 우리가 만든 고객 사이트 화면(Ref.01~15)이 영상의 주인공. 다른 회사 영상에는 있을 수 없다.
2. **만드는 과정** — 빈 화면 → 격자 → 한글 제목이 조판되고 → 사진이 들어가고 → 완성된 실제 사이트. "웹사이트를 만드는 곳"이 첫 화면에서 읽힌다.
3. **한글이 움직인다** — 자모가 모여 "한인 대표님들을 위한"이 조립되는 식. 해외 스톡 영상에는 나올 수 없는 장면.
4. **방문자에게 반응한다** — 마우스·스크롤에 따라 움직이는 화면은 녹화 영상이 아니라 그 자리에서 그려진다는 증거.
5. **하나의 서명** — 전환마다 같은 동작(예: 로고의 두 원이 열고 닫는 화면 전환), 같은 색·속도. 로고는 크게 쓰지 않고 이 움직임으로만 드러낸다.

## 만드는 방법
- **주 영상은 코드로**(HTML·Canvas·GSAP): 글자·화면·전환을 브라우저에서 직접 그림 → 선명하고 가볍고 반응형, 영상 파일 불필요. 같은 장면을 녹화해 SNS·소개용 MP4도 만든다.
- **실제 작업물 화면은 직접 녹화**: 고객 사이트를 실제로 스크롤하는 화면 녹화(Playwright), 기존 영상 작업물(Ref.01·02·07)은 원본 그대로.
- **Higgsfield(Seedance)는 보조로만**: 실제 작업물이 띄워진 노트북·휴대폰이 놓인 실제 공간(예: 그 업종의 매장 카운터) 같은 짧은 컷. 화면 속 내용은 생성하지 않고 실제 녹화를 합성해 고정(카메라 고정). 남은 예산 약 7.53 USD → 1080p 8초 1컷 또는 720p 약 20초.
- 장면마다 작은 캡션: "Ref.03 한식당 · 실제 제작 사이트"처럼 실제 분류명을 붙임.

## 방향 3가지
- **A. 라이브 제작 시연** — 히어로 자체가 사이트를 만드는 과정. 빈 화면 → 격자 → 한글 제목 조립 → 실제 작업물 3개가 차례로 완성 → PAUSE 첫 화면으로 정착(10~12초 루프). 코드 100%.
- **B. 실제 작업물 쇼릴** — 우리 고객 사이트들이 실제 기기 화면에서 스크롤되는 장면을 빠르게 이어 붙인 릴, 업종 캡션 포함. 일부 컷만 Seedance로 공간감.
- **C. A + B 혼합(추천)** — 첫 3초는 A(한글 조립·격자), 이어서 B(실제 작업물 릴), 마우스로 다음 작업물로 넘어감.

- 1회(사이트 첫 진입 때만, 반복 안 함): 빈 화면 → 격자 → 한글 제목 조립 → 실제 작업물이 완성되며 "제작비 1회 결제". 한 번 만들고 끝이라는 뜻이라 반복하지 않는다.

- 쓰는 원문: "0원 월·연 관리비 (무료)", "단 한 번의 제작비 외에, 매달·매년 나가는 비용이 없는 웹사이트를 만듭니다.", "제작비 1회 결제 · 이후 추가비용 $0 · 기술지원". 달 이름(1월~12월)은 새 표기 → 사용자 확인.

### 이음매 없는 반복 규칙
- 마지막 프레임과 첫 프레임을 완전히 같게(상태가 한 바퀴 돌아 제자리로).
- 끝나는 동작 금지(카메라가 다가가다 멈춤, 페이드아웃 등). 계속 도는 동작만: 일정 속도의 흐름, 원형 순환, 달력 순환.
- 코드 애니메이션은 시간 t를 주기로 나눈 나머지로 계산 → 수학적으로 이음매 0.
- Seedance 컷은 시작 이미지와 끝 이미지(end_image_url)를 같은 프레임으로 지정해 루프 생성, 카메라 고정.

## 최우선 목표(사용자, 2026-10-06): "웹사이트가 비싸 보이고, 영상까지 직접 만든다고? 대단한데" + 첫 3초 후킹
### 3단 구조
1. **후킹 0~3초 — 눈앞에서 사이트가 만들어진다.** 빈 크림색 화면에 실제 고객 사이트 하나가 조각조각 빠르게 조립(격자 → 한글 제목이 자모부터 모임 → 사진 → 버튼). 마지막 조각이 끼워지는 순간 화면이 뒤로 빠지며, 그 사이트가 실제 작업물 15개가 떠 있는 벽 중 하나였다는 게 드러난다(첫 진입 1회).
2. **고급스러움 증명 3~15초 — 무한 반복 구간.** 실제 작업물 화면들이 원근감 있게 천천히 흘러가는 벽(끝없이 순환). 마우스를 따라 벽이 살짝 기울고, 올리면 그 사이트가 살아나 스크롤된다. 한쪽에 달력이 1월→12월로 넘어가도 "월·연 관리비 0원"은 그대로.
3. **전환 — 문구와 버튼.** 헤드라인·설명·"무료 웹사이트 정밀 상담신청"·"카카오톡 1:1 실시간 상담"은 영상 위에 또렷하게 고정.

### 비싸 보이게 하는 요소
- 움직임 품질: 물리 기반 감속, 요소마다 시차를 둔 연출, 60fps, 끊김 없는 이음매.
- 디테일: 글자가 마스크 안에서 올라오는 등장, 버튼이 커서에 끌리는 반응, 사용자 정의 커서, 스크롤에 맞춰 장면이 바뀜.
- 절제: 색 3개(먹·크림·한 가지 강조), 넉넉한 여백, 큰 한글 조판.

### AI 느낌 안 나게 하는 규칙
- 사람 얼굴·손·글자·화면 내용은 생성하지 않는다. 화면 속은 항상 실제 작업물 녹화.
- 생성 영상은 빛·물·질감처럼 물리 현상만, 카메라 고정, 같은 색보정·필름 그레인으로 실제 촬영과 톤을 맞춤.
- 화면의 주인공은 실시간으로 그려지는 것(코드)과 실제 작업물 → 생성 티가 날 곳이 없다.

### "영상까지 만든다"를 알게 하는 방법
- 히어로가 처음부터 끝까지 하나의 연출된 영상처럼 짜여 있고(오프닝·순환·전환이 한 호흡), 포트폴리오에서 고객용 히어로 영상 작업도 함께 보여준다.
- 기존 사이트 원문에는 영상 제작 서비스 언급이 없음 → 실제로 제공하는 서비스인지, 문구로 내세워도 되는지 사용자 확인 필요.
