# PAUSE STUDIO 디자인 규칙 (2026-10, 32차 히어로 승인안 기준 · 2026-10-08 2차 개편 반영)

실제 값은 `site/src/styles/main.css` 맨 위 `:root` 토큰이 기준이다. 이 문서는 왜 그렇게 정했는지와 지켜야 할 규칙을 적는다.

## 1. 원칙
- **고감도**: 아티스트가 만든 것처럼. 폰트·배치·여백·움직임이 모두 의도가 보여야 한다. AI 양산형 웹사이트의 버릇(둥근 알약 버튼, 보라 그라데이션, 반짝이는 KPI 숫자, 과한 유리 효과, 아이콘 나열)을 쓰지 않는다.
- **실제만 보여 준다**: 포트폴리오·히어로 벽은 실제 고객 사이트 화면만. AI 광고영상 샘플은 "PAUSE가 가상의 브랜드로 직접 기획하고 만든 광고"라고 소개 글에서 밝힌다(가짜 고객 작업물로 보이게 하지 않음). BEFORE 화면은 가상 업체 이름으로 그린다.
- **읽히는 크기**: 강조할 곳은 크게, 나머지 글씨도 작게 줄이지 않는다(본문 최소 16.5px, 보조 글 최소 14.5px, 주석만 12.5~13.5px).
- **사진은 승인된 것만**: 28차(시네마틱 공간) 자산과 영수증 프린터 합성 사진은 사용자 반대로 쓰지 않는다. 대신 글자 디자인(예: 1년치 $0 내역)으로 보여 준다.

## 3. 서체 (무료 · 직접 호스팅 — 2026-10-08 사용자: 산돌 유료 웹폰트 대신 가장 비슷한 무드의 무료 폰트)
| 역할 | 서체 | CSS |
|---|---|---|
| 제목·가격·큰 숫자 | **PS Display** = 나눔스퀘어 네오 Bold(한글) + Archivo 폭 70·굵기 500(영문·숫자) | `--f-display` |

- 고른 이유: 실제 산돌 렌더와 같은 문장·크기로 무료 후보 10종을 나란히 비교. 나눔스퀘어 네오(디자인 산돌)는 네모틀을 채운 한글이 격동고딕2와 가장 가깝고, Regular는 그레타산스와 본문 밀도·줄바꿈이 거의 같음. 격동고딕2의 좁은 영문·숫자는 Archivo 좁은 폭으로 맞춤.
- 프리텐다드·SUIT·IBM Plex Sans KR은 1차 시안에서 "허접하고 AI 티가 난다"는 의견으로 제외.
- 파일: `site/public/fonts/*.woff2`(사이트 글자 묶음 + 나머지 한글 2,350자 묶음, unicode-range), `scripts/fonts.py`로 생성. 라이선스 SIL OFL 1.1.
- 한글 줄바꿈: `word-break: keep-all`(낱말 중간에서 끊지 않음).
- 글자 간격: 큰 제목 -0.035em, 중간 제목 -0.02em, 본문 기본, 영문 머리말(eyebrow) +0.16em 대문자(같은 줄의 한글은 +0.02em).
- **화면 글 표기(2026-10-08 사용자)**: 줄표(—·–)·하이픈(-)·별표(*)·참고표(※)를 쓰지 않는다. 쉼표·가운뎃점(·)·줄바꿈으로 나눈다. 점검(`tests/smoke.cjs`)이 화면 글·닫힌 답·대체 글까지 확인한다.
- **줄바꿈(사용자: 줄바꿈 신경 쓸 것)**: 문장 안 `\n`은 의도한 줄바꿈. 한 글자 낱말(쓸·더·웹·월·수…) 뒤에서는 줄이 바뀌지 않게 빌드 때 붙는 공백으로 바꾼다(`page.ts`의 glue). 본문·목록은 `text-wrap: pretty`, 제목은 `balance`.

## 5. 버튼 (32차 A안)
- **주 버튼**: 크림색 네모 블록 + 긴 화살표(30px). 마우스를 올리면 왼쪽에서 밝은 크림색이 차오르고 화살표가 6px 나아간다.
- **보조 버튼**: 얇은 선(크림 40%) 네모 + 카카오톡 말풍선 + 긴 화살표. 마우스를 올리면 크림색이 차오르며 글자가 검게.
- **글자 링크**: 밑줄(8px 띄움) + 짧은 화살표.
- 둥근 알약 모양·그림자·그라데이션 버튼은 쓰지 않는다. 높이 76(PC)/56(모바일).

## 6. 배치
- 최대 폭 1720px, 좌우 여백 `--gutter`(20~100px), 섹션 위아래 `--sec-pad`(96~176px).
- 섹션 머리: 영문 머리말(짧은 선 + 대문자) → 큰 제목(줄마다 아래에서 올라옴) → 소개 글.
- 페이지 순서(2026-10-08 개편): 히어로 → 포트폴리오 → WHY → 추천 대상 → **CHAPTER 01 WEBSITE**(BEFORE/AFTER · 요금 · 관리비 $0 · 과정) → **CHAPTER 02 AI VIDEO AD**(샘플 · 요금·규격·추가 작업·과정) → 질문 → 마무리 선언 → 문의. 장 첫 화면은 화면 폭의 17%(영상 장 12.4%)짜리 영문 단어 + 한글 이름 + 소개.
- 포트폴리오: 모든 작업물을 같은 크기 칸(16:10)에 — PC 4열, 1024~1279 3열, 모바일 2열. **화면은 자르지 않는다**: 칸 안에 원래 비율 그대로 띄우고(그림자·4px 모서리), 뒤에는 같은 화면을 흐리게 깔아 빈 곳을 채운다. 마지막 줄의 빈칸은 '다음 레퍼런스는 대표님의 브랜드입니다.' 상담 칸으로.
- BEFORE/AFTER: 틀은 실제 녹화(AFTER)의 비율 그대로, 가운데 손잡이로 비교. BEFORE는 평범한 사이트 빌더 기본 구성(흰 머리줄·사진 위 가운데 제목·서비스 카드 3개, 시스템 서체) — 일부러 못나게 만들지 않는다.
- 플랜 비교(견적서와 같은 원리): BUSINESS·ENTERPRISE는 'OO만의 기능'을 맨 위에 + 표시로 크게, 다른 플랜과 같은 기능은 아래 '기본 포함'에 **체크 표시 목록**으로(사용자: '기본 포함'이 안 보여 포함 안 된 것처럼 읽힘 → 흐리게 하지 않음). 가격은 'NZD'를 작게, 숫자를 크게. 버튼은 모두 '무료 상담받기'. 카드 아래에 '모든 플랜에 포함되는 무료 혜택' 띠(3칸)와 추가 안내사항. 같은 플랜을 두 번 보여 주지 않는다(서비스 칸 삭제).
- AI 광고영상: 가로 16:9·세로 9:16 기본 제공을 가장 먼저 크게(정책: 중요한 경쟁력), 상품 3개 카드(길이·화면·숏버전·수정·결과물 표), 공통 포함, 월간 상품은 따로 넓은 상자(웹사이트 관리비 $0과 헷갈리지 않게), 추가 작업 가격은 펼쳐 보기.
- 선: 1px, 크림 20% 또는 잉크 16%. 상자 대신 선으로 나눈다.

## 7. 움직임
- 히어로 인트로(3.4초): 어둠 속 흐릿한 작업물 벽이 다가오며 선명해짐 + 제목을 한글 자판으로 치듯 자모부터 조립(ㅅ→서→선) + 깜빡이는 커서 → 설명·버튼·서비스가 차례로.
- 작업물 벽: 세 줄이 서로 반대 방향으로 24초에 한 바퀴, 마우스에 따라 살짝 기울어짐, 화면에 보이는 카드의 영상만 재생(PC).
- 등장: 화면에 들어오면 26px 아래에서 1초 동안 올라옴. 제목은 줄마다 가려진 곳에서 올라옴.
- 가속 곡선: `--ease cubic-bezier(.2,.7,.1,1)`(빠르게 시작해 부드럽게 멈춤).
- **멈출 수 있어야 한다**: 5초 넘게 움직이는 것(작업물 벽·자동 재생 영상)에는 멈춤 버튼. '움직임 멈추기'는 사이트 전체에 적용되고 기억된다. 운영체제의 '동작 줄이기'를 켜면 인트로·자동 재생 없이 바로 최종 화면.
- 깜빡이는 표시(상담 가능 점)는 2번(5초 안)만. 예외: 히어로 제목 끝 커서는 계속 깜빡인다(사용자 요청) — '움직임 멈추기'·동작 줄이기면 멈춘다(html.still).
- **작은 움직임(2026-10-08, 절제된 한 가지씩)**: 포트폴리오 영상은 보이는 동안 늘 반복(마우스 불필요), 칸 위에서 '보기' 원 커서 · 장 제목 큰 영문이 스크롤에 따라 옆으로 흐름 · BEFORE/AFTER 손잡이가 처음 한 번 좌우로 움직여 안내 · 광고 샘플 탭의 진행 선, 한 편이 끝나면 다음 샘플(손대면 멈춤) · 질문 탭의 선택 표시가 미끄러져 이동, 답은 높이가 부드럽게 열고 닫힘, 원형 + 표시가 돌며 −로 · 계산기 숫자가 세면서 바뀌고 막대가 늘어남 · 카드 위 선이 그어지는 호버 · 상담 창·크게 보기는 떠오르며 열리고 짧게 사라지며 닫힘, 단계는 앞으로/뒤로 방향 · 접수 완료 체크가 그려짐 · 머리줄은 내려가면 숨고 올리면 나타나며 지금 보는 장에 밑줄 · 마무리 선언은 스크롤에 따라 단어가 하나씩 밝아짐.
- 동작 줄이기: 모든 전환을 즉시로(1ms). 자동 재생·자동 넘김·커서 깜빡임·큰 글자 흐름 없음.

## 8. 이미지·영상
- 포트폴리오: 실제 고객 사이트 화면(WebP + JPEG, 880/1920px), 영상은 H.264 MP4(소리 없음).
- AI 광고영상 샘플 4편(SOOM · ONDO COFFEE · SOUTHERN ROUTE · DAON HONEY, 모두 가상 브랜드): BEFORE = 사장님이 보내 줄 법한 평범한 사진(4:3), AFTER = 광고영상(16:9, H.264). 화면 위 글씨는 MaruBuri · Instrument Serif · Archivo(`tools/ad_edit.py`), AI 티가 나지 않게 색보정·비네팅·필름 그레인.
- BEFORE/AFTER의 BEFORE는 HTML로 그린 평범한 템플릿 화면(가상 업체 Kiwi Journeys · Sweet Moments Cakes, 사진은 Higgsfield 생성).
