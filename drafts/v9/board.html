PAUSE STUDIO — 9차 콘티: "사진만 보내주세요"

바뀐 점: 동대문을 실제 가게 모습으로(검은 간판·유리문·바깥 흰 의자) · ChillenQ는 설정샷 대신 실제 작업장 + 사이트 새 디자인 · 사이트 히어로가 영상이라는 재생 표시(일시정지 버튼·진행 막대)
흐름: 사진 보내기 → 사진이 영상으로 → 손님 휴대폰 속 사이트 → 실제 가게·현장 → 작업실 알림으로 반복 · 약 21초 · 자막 없음(화면 속 채팅·알림·사이트와 손동작으로 이야기)

화면 — 휴대폰은 모바일 레이아웃, 히어로는 영상(재생 표시)
